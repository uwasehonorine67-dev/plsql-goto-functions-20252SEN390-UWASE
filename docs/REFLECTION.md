# Reflection

I learned how PL/SQL GOTO statements can change the normal flow of program execution.

I also learned how to create and use stored functions in PL/SQL.

## 2. GOTO Statements

I learned how to define labels and use the GOTO statement to transfer execution to another labeled statement.

## 3. Functions

I learned how PL/SQL functions receive parameters, perform operations, and return values.

## 4. Exception Handling

I learned how exception handling can be used to deal with errors such as missing data.

## 5. Functions in SQL

I learned that stored functions can be called directly from SQL statements.

One challenge was understanding how GOTO statements work and where a GOTO statement can legally transfer control.

## 7. How I Solved the Challenges

I solved these challenges by testing each SQL program separately and checking the output and compilation errors.
